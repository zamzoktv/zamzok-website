ZAMZOK Website — نسخة أولية مجانية
====================================
الملفات:
- index.html: صفحات وأقسام الموقع.
- styles.css: الهوية والتنسيق المتجاوب.
- script.js: قائمة الموبايل والسنة التلقائية.
- assets/zamzok-banner.png: صورة الغلاف العريضة.
- assets/zamzok-logo.png: الشعار الدائري.

التجربة:
افتح index.html في متصفح حديث. لعرضه على الإنترنت مجانًا، ارفع محتويات المجلد إلى مستودع GitHub ثم فعّل GitHub Pages، أو انشر المجلد عبر Cloudflare Pages.

ملاحظات:
- روابط يوتيوب وتيك توك مضبوطة على الحسابات التي أرسلها صاحب الموقع.
- بطاقات الفيديو الحالية أمثلة تصميمية؛ يلزم استبدالها بروابط الفيديوهات الحقيقية.
- لا توجد لوحة إدارة أو جلب تلقائي للفيديوهات في هذه النسخة الأولية.
- خط Google Fonts يحتاج اتصال إنترنت؛ الموقع يستخدم خطوطًا بديلة إذا لم يتوفر.
